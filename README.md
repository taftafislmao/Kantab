# KanTab

A simple, fast task manager for Windows. Organize work with boards, lists, and notes — all in one compact desktop app.

## What it does

- **Boards** — drag cards between columns, add checklists, set due dates and priorities
- **Tasks** — see everything in one list, filter and sort, check things off
- **Notes** — jot down ideas, pin the important ones, find them instantly
- **Search** — press `Ctrl+K` to find any task, note, or board in seconds
- **Command Palette** — press `Ctrl+Shift+P` for quick actions
- **Backup** — export your data to a file and import it back anytime
- **Reminders** — get notified before a task is due or when it's overdue
- **Works offline** — your data is saved locally and always available

## Get started

Download a release, or run from source:

```bash
dotnet run --project KanTab/KanTab.csproj
```

That's it — no account required to get started.
